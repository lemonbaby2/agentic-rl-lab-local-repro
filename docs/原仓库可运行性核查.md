## 结论

原仓库所有入口脚本都依赖 `pytrio` 客户端，训练与采样在云端执行，
本机只承担数据、reward 与 loss 计算。因此「用本机 GPU 复现」必须补上训练器，
这正是本仓库 `local_repro/trainer.py` 的作用。
